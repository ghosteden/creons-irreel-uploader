Privacy Policy – Créons l'Irréel Uploader

Last updated: November 21, 2026

"Créons l'Irréel Uploader" (the "Tool") is a private command-line script used by the owner of the YouTube channel Créons l'Irréel to upload and schedule videos of their own game projects on their own channel. It is not offered to the public and has a single user: the channel owner.

What data the Tool accesses

The Tool uses the YouTube Data API v3 with the https://www.googleapis.com/auth/youtube.upload scope, only to:

  • upload video files chosen by the channel owner from their own computer;
  • set the title, description, tags, language, category, visibility and scheduled publication date of those videos;
  • set a custom thumbnail for those videos.

It does not read, collect or analyse any other YouTube data (no comments, no subscribers, no viewer data, no analytics).

How data is stored

The OAuth token issued by Google is stored only on the channel owner's own computer, in a local file outside any shared folder. No data is sent to any server other than Google's APIs. Nothing is shared with, sold to or disclosed to third parties.

Revoking access

Access can be revoked at any time from the Google Account security settings: https://myaccount.google.com/permissions. Deleting the local token file also removes the Tool's access from that computer.

Google and YouTube policies

By using the Tool, the user agrees to the YouTube Terms of Service. Data accessed through YouTube API Services is also subject to the Google Privacy Policy.
